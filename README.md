## 專案簡介

Humanizer-zh-TW 是一個用於去除文字中 AI 生成痕跡的工具，幫助你將 AI 生成的內容改寫得更自然、更像人類書寫的文字。

本專案適用於：

- 編輯和審閱 AI 生成的內容
- 讓文章讀起來更自然
- 學習辨識 AI 寫作的常見模式

## 使用

### 基礎用法

在 Codex、Claude Code 或 Antigravity 中，你可以透過以下方式使用 Humanizer：

#### 1. 在 Codex 中使用

直接要求 Codex 使用此技能：

```
請使用 humanizer-zh-tw 技能改寫以下文字，讓它更自然：

[貼上你的 AI 生成文字]
```

也可以要求 Codex 處理工作區中的檔案：

```
請使用 humanizer-zh-tw 技能改寫 article.md
```

#### 2. 直接呼叫技能（Claude Code）

```
/humanizer-zh-tw 請幫我人性化以下文字：

[貼上你的 AI 生成文字]
```

#### 3. 在對話中使用

```
請用 humanizer 幫我改寫這段話，讓它更自然：

這個專案作為我們團隊致力於創新的證明。此外，它展現了我們在不斷演變的技術局勢中的關鍵角色。
```

#### 4. 處理檔案內容

```
請使用 humanizer-zh-tw 技能改寫 article.md，並直接更新檔案
```

### 使用場景範例

#### 場景 1：改寫行銷文案

**輸入：**

```
/humanizer-zh-tw
坐落在風景如畫的台北市中心，這家咖啡館擁有豐富的文化底蘊和令人讚嘆的裝飾。它作為城市咖啡文化的焦點，為顧客提供無縫、直觀和充滿活力的體驗。
```

**輸出範例：**

> 這家咖啡館位於台北市中心，店內裝潢是主要特色。原文未提供餐點、價格或服務等具體資訊。

#### 場景 2：改寫學術摘要

**輸入：**

```
/humanizer-zh-tw
本研究深入探討了機器學習在醫療診斷中的關鍵角色，凸顯其在不斷演變的醫療局勢中的重要性。此外，它為該領域的未來發展奠定了堅實的基礎。
```

**輸出範例：**

> 本研究分析機器學習在醫療診斷中的應用。原文未說明研究問題、方法或結果，無法判斷研究貢獻。

#### 場景 3：改寫部落格文章

**輸入：**

```
/humanizer-zh-tw
人工智慧不僅僅是一種技術，它是我們思考未來方式的革命。業界專家認為這將對整個社會產生長遠影響。
```

**輸出範例：**

> AI 可能改變工作方式，也可能影響社會。原文沒有提供具體例子或資料，無法判斷影響範圍。

## 偵測的 AI 寫作模式

本工具整理了 **23 種** 常見的 AI 寫作痕跡，分為四大類：

### 📝 內容模式（6 種）

1. 過度強調意義、遺產和更廣泛的趨勢
2. 過度強調知名度和媒體報導
3. 句尾附加空泛評論
4. 宣傳和廣告式語言
5. 模糊歸因和含糊措辭
6. 模板化的「挑戰與未來展望」段落

### 🔤 語言和語法模式（6 種）

7. 過度使用的「AI 詞彙」
8. 避免使用「是」（繫詞迴避）
9. 否定式排比
10. 刻意湊成三點
11. 刻意換詞（同義詞循環）
12. 虛假範圍

### 🎨 風格模式（5 種）

13. 破折號過度使用
14. 粗體過度使用
15. 粗體小標清單
16. 表情符號
17. 中英文標點混用

### 💬 對話模式與贅詞（6 種）

18. 對話殘留
19. 知識截止日期免責聲明
20. 過度討好的語氣
21. 填充短語
22. 過度保留
23. 空泛的正面結論

## 手動使用方法

### 基本流程

1. **辨識 AI 模式** - 對照 `SKILL.md` 中列出的 23 種模式掃描文字
2. **重寫問題片段** - 用自然的表達替換 AI 痕跡
3. **保留核心含義** - 確保資訊完整性
4. **維持適當語調** - 匹配文字應有的風格
5. **符合原本文體** - 不擅自加入觀點、情緒或事實

### 關鍵原則

#### 保留作者語氣，也保留事實界線

自然的文字不等於一律加入情緒或第一人稱。改寫時應配合原文用途：

- **依文體表達觀點** - 個人文章可保留立場，正式文件應客觀陳述
- **變化節奏** - 混合使用長短句
- **如實呈現不確定性** - 不用模糊措辭掩飾資料不足
- **維持文章用途** - 不把技術文件改成個人心得
- **不得虛構細節** - 不自行補寫來源、數字、引言或事例

#### 範例對比

**改寫前（AI 味道）：**

> 新的軟體更新作為公司致力於創新的證明。此外，它提供了無縫、直觀和強大的使用者體驗——確保使用者能夠高效地達成目標。這不僅僅是一次更新，而是我們思考生產力方式的革命。

**改寫後（自然化）：**

> 這次軟體更新改善了操作流程。原文未提供功能細節或測試結果，因此無法判斷實際成效。

**變化：**

- 刪除了誇大的象徵意義（「作為……的證明」）
- 刪除了 AI 詞彙（「此外」、「無縫」）
- 刪除了刻意湊成的三項形容詞（「無縫、直觀和強大」）
- 刪除了否定式排比（「不僅僅是……而是……」）
- 指出原文缺少可驗證的具體資訊

## 常見 AI 詞彙警示列表

以下詞彙在 AI 生成文字中出現頻率異常高：

- 此外、至關重要、深入探討、強調
- 持久的、增強、培養、獲得
- 凸顯、相互影響、複雜/複雜性
- 局勢（抽象名詞）、關鍵性的、展現
- 交織（抽象比喻）、證明、強調
- 寶貴的、充滿活力的
